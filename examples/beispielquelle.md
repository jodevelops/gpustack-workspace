# Fiktive Beispielquelle: Projekt Morgenlicht

Alle Sammlungs-, Objekt- und Projektangaben in dieser Datei sind frei erfunden.
Die Datei dient ausschließlich dem Test von Upload, Suche und Quellenbelegen.

Das Beispielprojekt Morgenlicht umfasst fünf digitale Testobjekte. Zwei davon
zeigen eine Landschaft, zwei eine Brücke und eines einen Lesesaal. Die
Beispieldaten verwenden Bern und Thun als Ortsangaben; ein Ortsfeld bleibt
absichtlich leer, damit die Datenprüfung einen fehlenden Wert erkennen kann.

Der Projektplan sieht zuerst eine Prüfung der Ortsangaben und anschließend
eine Kontrolle der Datierungen vor. Im Testablauf sind zwei Objekte geprüft,
zwei ungeprüft und eines muss nochmals kontrolliert werden.

Eine mögliche Testfrage lautet: Welche Arbeitsschritte sind vorgesehen?
Die Antwort soll auf diesen Text verweisen. Für genaue Gesamtzahlen aus der
CSV-Tabelle muss die vollständige Tabelle berechnet werden; Suchausschnitte
allein ersetzen diese Berechnung nicht.
